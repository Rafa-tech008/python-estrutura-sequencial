# Python - Estruturas Sequenciais

## 📖 Objetivo

Este repositório reúne exercícios acadêmicos desenvolvidos em Python com foco na aplicação de estruturas sequenciais, operações matemáticas, entrada e saída de dados e desenvolvimento da lógica de programação.

## 📂 Conteúdo

O repositório contém exercícios sobre:

- Entrada e saída de dados;
- Operações aritméticas;
- Variáveis e tipos de dados;
- Resolução de problemas utilizando estruturas sequenciais.

## 💻 Tecnologias

- Python 3

## ▶️ Como executar

1. Instale o Python 3 em seu computador.
2. Clone este repositório ou faça o download dos arquivos.
3. Execute o arquivo desejado pelo terminal:

```bash
python nome_do_arquivo.py
```
